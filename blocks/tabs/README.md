# tabs

Custom **tabs** block. Purpose: Interactive tab switcher that reveals one content panel at a time.

## Authoring (Document Authoring)

Model: `container`

Single block table. Content: One row per tab: cell 1 = tab label, cell 2 = tab panel content.
